Sign in to update the site

This connects the page to the place the website's files are kept. You do it once on each device; after that this page opens straight to the weekly update.

Where does the access token come from?
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
  2. Create a token that can reach only the website's repository.
  3. Under Repository permissions, set Contents to Read and write. Nothing else is needed.
  4. Copy the token and paste it above.

The token is kept in this browser on this device only. Use Sign out to remove it.
